# Проект "Виджет банковских операций клиента"

## Описание:

Проект "Виджет банковских операций клиента" помогает отслеживать детали банковских оперций

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:UlianaKrasnova3/homework.git

или

https://github.com/UlianaKrasnova3/homework.git
```



## Использование:

Функции в проекте помогут создать маску номера карты, номера счета, помогают отформатировать дату.
В модуле generators генераторные функции помогают анализировать операции и генерировать номера карт.
