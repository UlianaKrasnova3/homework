# Проект "Виджет банковских операций клиента"

## Описание:

Проект "Виджет банковских операций клиента" помогает отслеживать детали банковских оперций

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/myblog.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
```


## Использование:

Функции в проекте помогут создать маску номера карты, номера счета, помогают отформатировать дату.
